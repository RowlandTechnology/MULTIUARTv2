# MultiUART Flowcode Component

Flowcode component for the MULTIUART / SPI2UART board, for Flowcode 6, 7 and 8.

| File | Description |
|------|-------------|
| `MULTIUART.fcpx` | Component file. Add it to Flowcode's components folder to use the board in your programs. |
| `MULTIUART.fcfx` | Source of the component, open in Flowcode to view or modify it. |
| `Component Test.fcfx` | Example program using the component. |

These files are not used by the Arduino IDE.
